# Frontend - Calisthenics Fitness

Next.js frontend with modern UI and interactive assessment.

## Setup

1. Install dependencies:
```bash
npm install
# or
yarn install
```

2. Run development server:
```bash
npm run dev
# or
yarn dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
npm start
```

## Pages

- `/` - Homepage with features and pricing
- `/assessment` - Interactive quiz (18 questions)
- `/results` - Display generated plans and PDF download

## Features

- Apple glass-morphism design
- Smooth animations with Framer Motion
- Mobile responsive
- Progress tracking
- Image-based questions
