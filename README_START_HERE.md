## ⚠️ Troubleshooting

### Backend Won't Start?

**Error: "Virtual environment not found"**
- The batch file will try to create it automatically
- If it fails, make sure Python is installed: `python --version`

**Error: "Port 8000 already in use"**
- Close any other programs using port 8000
- Or restart your computer

**Error: "Module not found"**
- The batch file will auto-install dependencies
- Wait for it to finish installing

### Frontend Won't Start?

**Error: "npm is not recognized"**
- Install Node.js from: https://nodejs.org/
- Restart your computer after installing

**Error: "Port 3000 already in use"**
- Close any other programs using port 3000
- The batch file will try a different port automatically

**Error: "Dependencies not installed"**
- The batch file will auto-install them
- Wait for `npm install` to complete
